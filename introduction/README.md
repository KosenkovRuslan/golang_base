## go mod init ${moduleName}
Создает файл go.mod, который описывает зависимости используемые для проекта.
Как аналогия - package.json для фронта. Обычно эту команду выполняют один раз в самом корневом каталоге проекта.

## go run ${fileName}
Компиляция и запуск программы.
Под капотом происходит 3 шага:
1) Компиляция кода во временную папку
2) Запуск получившегося временного файла
3) Удалялкние временного файл после того, как программа завершит работу.

## go build
### Сборка проекта в исполняемый файл.
Флаги:
- -o <путь/имя_файла> — Задает имя и место сохранения готового файла. По умолчанию Go называет файл по имени папки (или main).

### Под разные ОС собираются разные файлы
Пример: go build -o myapp main.go
- GOOS - целевая операционная система (windows, linux, darwin для macOS)
- GOARCH - архитектура процессора (amd64, arm64, 386)

Пример: GOOS=windows GOARCH=amd64 go build -o app.exe .

### Отладка
go install github.com/go-delve/delve/cmd/dlv@latest

Команды для VS Code:
- Cmd + F5 - Запустить отладку (Start Debugging).
- Cmd + Shift + F5 - Остановить отладку (Stop Debugging).
- Cmd + F10 - Выполнить шаг не заходя в функцию (Step Over).
- F11 - Выполнить шаг с входом функцию (Step Into) - надо настраивать.
- Cmd + Shift + F11 - Выйти из функции (Step Out).
- Cmd + Shift + F5 - Перезапустить отладку (Restart Debugging).
- Cmd + Shift + Y - Открыть панель отладки (Debug Console).

Пользоваться отладчиком, когда вы перестаёшь понимать, что в твоём коде происходит и почему ты получаешь определенный результат.
